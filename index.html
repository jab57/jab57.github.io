About

Jose Bird,
PhD

I build open-source AI systems at the intersection of computational biology and large language models. My work focuses on making gene regulatory network analysis and therapeutic target discovery accessible, reproducible, and composable — integrating multi-omic data sources through LangGraph multi-agent architectures and the Model Context Protocol (MCP).

RegNetAgents and CASCADE are the first two components of a broader orchestration ecosystem designed to answer complex biological questions that no single tool can address alone. Both are released under open licenses with Zenodo DOIs for citability in peer-reviewed research.

Project 01

RegNetAgents

A multi-agent LangGraph system for gene regulatory network analysis, combining ARACNe-derived TCGA networks with Reactome pathway enrichment and InterPro domain classification.

  • GREmLN ARACNe networks — 11M cells, 10 cell types (CELLxGENE Census)
  • TCGA tumor-state ARACNe networks for 8 cancer types
  • Reactome pathway enrichment analysis per cell type
  • InterPro protein domain classification
  • LangGraph multi-agent DAG coordination
  • 10 immune and epithelial cell type contexts
  • MCP server — composable with Claude Desktop

Project 02

CASCADE

Comprehensive multi-omic perturbation analysis integrating seven independent evidence sources — network propagation, STRING PPI, LINCS L1000, DoRothEA, DepMap CRISPR, super-enhancers, and cBioPortal — to identify and rank therapeutic targets.

Seven independent evidence sources fan into a single evidence synthesis node, producing ranked therapeutic target reports per gene and cell type.
  • Network propagation from gene perturbation signals
  • STRING protein–protein interaction scoring
  • LINCS L1000 transcriptional perturbation data
  • DoRothEA transcription factor regulon activity
  • DepMap CRISPR essentiality screen integration
  • Super-enhancer landscape analysis
  • cBioPortal somatic mutation frequency

Built On

GREmLN

Graph-based single-cell foundation model that incorporates gene regulatory network topology into transformer attention — providing the gene embeddings and network structure that underpin RegNetAgents and CASCADE analyses.

Califano Lab · Chan Zuckerberg Biosciences NY

ARACNe

Algorithm for the Reconstruction of Accurate Cellular Networks. Mutual information-based approach for inferring transcription factor regulons from gene expression data, providing the regulatory network backbone used across both tools.

Califano Lab · Columbia University

LangGraph

Graph-based orchestration framework for multi-agent AI workflows. Provides the stateful DAG coordination layer that manages parallel agent execution, state passing, and conditional routing across both RegNetAgents and CASCADE.

LangChain, Inc.

Claude / Anthropic

Large language model powering the synthesis layer in both tools — integrating structured evidence from multiple agents into coherent biological interpretations via the Anthropic API and Model Context Protocol (MCP).
