The central question driving this work: can AI systems learn the regulatory logic of the cell well enough to predict what happens when you intervene — and use that to accelerate disease treatment?

RegNetAgents and CASCADE are the first steps toward that answer — open-source systems that compose multi-omic evidence into reproducible gene regulatory and perturbation analyses. Both carry Zenodo DOIs for peer-reviewed citability and are built for disease treatment discovery pipelines, not just the computational biology literature.

A background in process optimization shapes how I frame the problem: gene regulatory networks as feedback-controlled systems, disease intervention as the question of which perturbation, at which node, produces the desired cellular outcome.

Project 01

RegNetAgents

A multi-agent LangGraph system for gene regulatory network analysis, combining ARACNe-derived TCGA networks with Reactome pathway enrichment and InterPro domain classification.

LLM Synthesis (Claude)
ESR1 is confirmed as a master regulator in breast cancer epithelial cells — the only cell type where it is active across the GREmLN network. With 80 upstream regulators and 170 downstream targets, it sits at the center of a tightly controlled transcriptional hub. The dominant pathway signal is CHD2-driven chromatin remodeling, identifying CHD2 as the epigenetic gatekeeper of ESR1 expression and a potential upstream intervention point. As a nuclear receptor, ESR1 is highly druggable via both inhibition (e.g., fulvestrant) and activation strategies. Cross-referencing with CASCADE's perturbation analysis of the same gene reveals the full picture: RegNetAgents maps the regulatory architecture of ESR1, while CASCADE quantifies the therapeutic consequences of disrupting it.

Project 02

CASCADE

Comprehensive multi-omic perturbation analysis integrating eight independent evidence sources — GREmLN embeddings, network propagation, STRING PPI, LINCS L1000, DoRothEA, DepMap CRISPR, super-enhancers, and cBioPortal — orchestrated by LangGraph to identify and rank therapeutic targets.

Here's what CASCADE reveals when you ask what happens if you knock out ESR1 in breast cancer cells — ranked by evidence strength across eight independent data sources, from network propagation to CRISPR screens:

LLM Synthesis (Claude)
ESR1 knockdown in breast cancer epithelial cells disrupts a master regulatory hub affecting 3,080 downstream genes — with GATA3, MYB, and FOXA1 as the highest-confidence effectors, each corroborated by three independent evidence sources. STRING confirms direct physical coupling to IGF1R and BRCA1 (score 0.999), while DepMap CRISPR shows strong lineage-selective essentiality in breast (Chronos −0.318 across 53 lines) with minimal pan-cancer toxicity (−0.047), making ESR1 a clean lineage-specific target. Super-enhancer presence in MCF-7 cells and BRD4 sensitivity open a parallel epigenetic intervention angle via JQ1/OTX015. The DoRothEA A-confidence regulon (CCND1, E2F1, AKT1) further positions ESR1 as a master orchestrator of ER+ breast cancer proliferation.

Try It

Query Any Gene in Claude Desktop

Both tools ship as MCP servers — connect them to Claude Desktop (Anthropic's AI assistant) and run gene regulatory and perturbation analyses directly in conversation, no code required. If you can type a question, you can run the analysis.

1
Install the tool
Clone RegNetAgents or CASCADE from GitHub and follow the setup instructions in the README. Requires Python and a Claude API key.
2
Connect to Claude Desktop
Add the MCP server entry to your Claude Desktop config file — the exact snippet is in each repo's README.
3
Query any gene
Ask Claude: "Analyze ESR1 in breast cancer epithelial cells" — and get a full regulatory or perturbation report in seconds.
